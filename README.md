# R.B Shop | فروشگاه آنلاین خشکبار و زعفران اعلای افغانستان

فروشگاه آنلاین تخصصی خشکبار، میوه‌جات خشک و زعفران ممتاز افغانستان در آلمان و سراسر اروپا.
مدیریت: **رمضان بختیاری** (R. Bakhtyary) | Büsum, Germany

---

## 🌟 ویژگی‌های پروژه
- **طراحی مدرن و ریسپانسیو:** طراحی کاملاً اختصاصی سازگار با موبایل، تبلت و کامپیوتر.
- **سبد خرید هوشمند:** ثبت اقلام با محاسبه خودکار قیمت به یورو (€) و هزینه ارسال پستی با DHL.
- **ثبت سفارش مستقیم در واتساپ:** فرم استاندارد مشخصات پستی (خیابان، پلاک، کد پستی PLZ، شهر و کشور) با ارسال پیام سازمان‌یافته به واتساپ دکان (`0049 172 9343833`).
- **دیتابیس ابری زنده (Supabase):** اتصال بلادرنگ به PostgreSQL ابری جهت ذخیره محصولات، سفارشات و تنظیمات.
- **پنل مدیریت اختصاصی و ساده (`/rb-shop-admin`):**
  - تغییر آنی قیمت‌ها با کلیدهای `+` و `-` (بدون نیاز به تایپ).
  - کلید یک‌لمسی موجود / تمام شد برای هر کالا.
  - فرم افزودن جنس جدید با گالری لمسی انتخاب عکس.
  - ویرایش آدرس و تلفن دکان.
  - پشتیبانی از رمز عبور پیش‌فرض: `rb2026`.
- **آماده استقرار روی Vercel:** همراه با کانفیگ `vercel.json` برای مسیردهی تمیز (Clean URLs) و جلوگیری از خطای ۴۰۴ در رفرش صفحات.

## 🚀 ساختار فایل‌ها
```
rb-shop/
├── index.html              # صفحه اصلی فروشگاه
├── rb-shop-admin/
│   └── index.html          # پنل مدیریت فروشگاه (مسیر /rb-shop-admin)
├── rb-shop-admin.html      # روت کمکی پنل ادمین
├── vercel.json             # تنظیمات مسیریابی و امنیت Vercel
├── supabase_schema.sql     # کدهای ساخت جداول در Supabase
├── start_rb_shop.bat       # اسکریپت اجرای لوکال با دو بار کلیک
└── assets/                 # عکس‌ها، لوگو و فونت‌های فارسی وزیرمتن
```

---

## 🛠️ اجرای محلی (Localhost)
با دو بار کلیک روی فایل `start_rb_shop.bat` یا اجرای دستور:
```bash
python -m http.server 3000
```
سپس در مرورگر باز کنید:
- فروشگاه: `http://localhost:3000`
- پنل ادمین: `http://localhost:3000/rb-shop-admin` (رمز: `rb2026`)
